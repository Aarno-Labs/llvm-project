# clang-refold layer manifest.
#
# One line per C/C++ file under clang-tools-extra/clang-refold:
#
#   <path relative to the tool root>  <layer>  [# note]
#
# Layers, lowest first: support, model, carriers, analysis, proof, planning,
# emission, core, tool.  A file may include files in its own layer or any lower
# layer.  docs/Architecture.md defines each layer; utils/check_refold_layers.py
# enforces this file, and a .cpp must share its header's layer.
#
# Assignments were made by reading each file's purpose, types and consumers,
# not by directory.  When a file is added, split or moved, update this file in
# the same commit.  A note records why a non-obvious assignment was chosen.
